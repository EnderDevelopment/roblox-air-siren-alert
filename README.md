# Air Siren Scripts

This project provides a set of scripts for Roblox that allows players to trigger an air siren sound by clicking a button. The scripts include a server-side button click handler and a client-side siren control script. The main features include event-driven siren activation, sound management, and player interaction.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `StarterPlayerScripts` folder in the Explorer.
4. Create a new script and name it `ButtonClickHandler.server.lua`.
5. Copy the contents of the `ButtonClickHandler.server.lua` file from the project and paste it into the new script.
6. Create another new script and name it `SirenControl.client.lua`.
7. Copy the contents of the `SirenControl.client.lua` file from the project and paste it into the new script.
8. Replace the placeholder sound ID in the `SirenControl.client.lua` script with your actual sound ID.
9. Ensure the button in your game has a `ClickDetector` component attached to it.

## Use

1. Start the Roblox game.
2. Click on the button with the `ClickDetector` component attached to it.
3. The siren sound will start playing for all players.
